# tech-stuff

A curated hub for people into coding, AI, software, setups, design, and tech.

The goal is simple: **one place to find actually useful tech resources without digging through random posts and outdated lists.**

## What you'll find

- 🤖 AI tools for coding
- 💻 Developer apps and editors
- 🖥️ Windows, Linux, and macOS resources
- 📰 AI + tech news sources
- 🌐 Useful websites
- 🎨 Logos, banners, profile assets, and emojis
- 🔧 Developer tools
- 🔒 Privacy and browser picks
- 📚 Learning resources

## Website

The site lives directly in this repository and is designed to work with GitHub Pages.

### Emoji library

[`emojis.html`](emojis.html) is a searchable collection of 52 transparent tech emojis. The source files live in [`/emojis`](emojis/) as SVGs, and the website can export transparent PNG versions for services such as Discord.

## Contributing

Found something that belongs here? Open an issue or pull request.

Please keep submissions:
- useful
- safe
- actively maintained when possible
- relevant to developers, creators, AI users, or tech enthusiasts
- free of referral spam

See [CONTRIBUTING.md](CONTRIBUTING.md) for details.
