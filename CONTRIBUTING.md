# Contributing to tech-stuff

Thanks for helping improve the collection.

## Suggesting a resource

Open an issue with:

- **Name**
- **Category**
- **Link**
- **What it does**
- **Why it belongs here**
- **Free / Paid / Freemium**

## Good submissions

We prefer resources that are:

- useful to developers or tech enthusiasts
- reputable
- actively maintained
- clearly documented
- safe to recommend

## Avoid

Please do not submit:

- referral spam
- malware or suspicious downloads
- piracy resources
- abandoned tools without a strong reason
- duplicate entries
- low-quality AI-generated resource dumps

## Pull requests

Keep pull requests focused. If you're adding multiple resources, group them by category and explain what changed.

Thanks for contributing.
