# Emoji library

Transparent tech emoji assets used by the Tech Stuff website.

## Formats

The source assets in this folder are SVG files with transparent backgrounds.

The website at `/emojis.html` can also export any asset as a **256×256 transparent PNG**, which is useful for Discord custom emojis.

## Included

58 assets covering:

- operating systems
- AI products
- developer tools
- browsers
- platforms
- gaming
- social apps
- utility icons

## Sources

Brand vectors are sourced from projects such as:

- Simple Icons (v16.34, brand colors from its data)
- Devicon (multicolor developer logos)
- Lobe Icons (AI product logos)

A few generic utility assets (such as Folder, Zip Folder, Terminal, File Explorer, and Xbox-style artwork) are maintained directly in this repository.
